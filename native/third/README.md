# Third-party headers kept here

`dr_mp3.h`, `dr_wav.h`, `dr_flac.h` — David Reid's dr_libs, single-file audio
decoders, from https://github.com/mackron/dr_libs at commit
35b5c392cc15456736c440a68dbe073178bbffe0 (2026-10-30; dr_mp3 0.7.4, dr_wav
0.14.6, dr_flac 0.13.4), unchanged. Dual-licensed public domain (Unlicense) or
MIT No Attribution: `LICENSE.dr_libs`. Used by `native/audioplay.cpp` (the Files
card's audio player) on every platform.
